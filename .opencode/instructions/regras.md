# Regras do Projeto

## Commit e Push
- Nunca faca commit ou push sem autorizacao explicita do usuario.
- Sempre mostre um resumo do que sera commitado (`git status` e `git diff`) antes de pedir permissao.
- Commits devem usar ingles ou portugues consistente.

## Scripts de Deploy
- Scripts estao em `deploy/`, `deploy-interativo/` e `configuracao-filas/`.
- Nao modifique os scripts sem consultar o usuario.
